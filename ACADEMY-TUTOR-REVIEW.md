# ИИ-наставник Academy — версия на проверку

Статус: улучшение находится в отдельной ветке, PR #2. Не сливать в `main` и не развёртывать новый серверный код до пользовательской проверки. Сейчас на рабочем сайте действует старая версия наставника.

## Что изменилось и зачем

- На сервере подготовлены 32 оригинальные учебные рубрики: 14 QA, 14 English и 4 Python — только действительно опубликованные упражнения. У каждой есть цель, задача, наблюдаемые критерии и типичная ошибка. Текст критериев, отправленный из браузера, не считается источником истины.
- «Объясни» даёт краткое объяснение и вопрос; «Подсказка» — направление без готового решения; «Дай задание» — одно новое упражнение; «Разбери ответ» — замечания по конкретной работе без выдуманного зачёта.
- Кнопка «Разобрать мой текст с ИИ» в уроке **по согласию** переносит ответ в поле наставника. Перед расходным запросом можно отредактировать текст, затем отдельно нажать «Отправить». Черновик удаляется из временного хранилища при получении.
- История ограничена шестью репликами и не синхронизируется в облако. Смена предмета обнуляет диалог. Во время запроса переключение блокируется; после сетевого сбоя текст возвращается в поле.

## Безопасность и реальные ограничения

Серверная функция `academy-tutor` проверяет JWT и роль `owner`; ключ OpenAI находится только в секрете Supabase `ACADEMY_OPENAI_API_KEY`. Браузер содержит лишь публичный ключ **Supabase**, который нельзя путать с секретом OpenAI. Наставник не пишет в SEVER, календарь, оценки и облачный прогресс. Квота: до 5 запросов за 5 минут и до 30 за последние 24 часа; не денежный предел. Не вводи в учебные сообщения пароли, API-ключи и персональные данные. Вызов OpenAI сделан с `store: false`, но это не гарантия отсутствия всех журналов обработки.

ИИ не исполняет код, не наблюдает реальные приложения и не проверяет устную речь. Его письменный разбор может быть ошибочным и не заменяет сертификацию.

## Точная активация OpenAI API — действия владельца

**Шаг 1. Проверь, что куплены именно кредиты API.** Подписка ChatGPT Plus/Pro оплачивается отдельно и сама по себе не даёт API-баланс. Открой https://platform.openai.com/settings/organization/billing/overview и проверь баланс/способ оплаты. Если тебе ещё нет 18 лет, платёжные действия нужно согласовать с родителем или опекуном. Не включай автопополнение без сознательного решения; суточная квота Academy ограничивает число запросов, но не гарантирует фиксированную стоимость.

**Шаг 2. Создай ключ в OpenAI.** Открой https://platform.openai.com/api-keys (или выбери нужный проект → API Keys), создай обычный секретный API-ключ с названием `Academy`. Если задаёшь Restricted permissions, разреши **Write** для `Responses API` (`/v1/responses`), иначе первый запрос вернёт отказ; ключ «Read only» не подходит. Убедись, что в проекте разрешена модель `gpt-5.6-terra`. Если ключ уже создан и нигде не раскрывался, можно использовать его; повторная покупка не требуется. **Не присылай значение ключа в чат, не снимай с него маску на скриншотах, не коммить в GitHub.**

**Шаг 3. Положи ключ в нужный проект Supabase.** Открой прямо эту страницу: https://supabase.com/dashboard/project/vdhazibkfpgclcwyvvbi/functions/secrets . Если прямой адрес изменился: Dashboard → проект `sever-planner` (ID `vdhazibkfpgclcwyvvbi`) → Edge Functions → Secrets. Добавь пару:

- **Name / Key:** `ACADEMY_OPENAI_API_KEY`
- **Value:** полный секретный ключ **OpenAI** (без `Bearer`, кавычек, пробелов и других приставок).

Нажми **Save**. Убедись, что в списке отображается **имя секрета**, но не пытайся читать или показывать значение. Вводить значение в SQL Editor, GitHub Secrets, сайт Academy, браузерную консоль или `ai.js` **не нужно**. После сохранения секрета Supabase не требует повторного развёртывания функции только из-за переменной окружения.

**Шаг 4. Пока PR на проверке.** После сохранения ключа действующий `https://golovalisaia-hub.github.io/-/ai.html` сможет показать, что ключ **обнаружен** (если ты вошёл под владельцем). Этот индикатор **не проверяет** баланс или ответ модели: только первый успешный вопрос подтверждает реальное подключение. Напиши помощнику «Ключ добавлен» **без значения ключа** и дай добро на выпуск PR, когда ознакомишься с изменениями. Мы сначала развернём новую `academy-tutor` с ОБОИМИ файлами `index.ts` и `rubrics.ts` и `verify_jwt=true`, затем сольём PR в `main`. Без этого новая страница и старая серверная функция будут несовместимы.

**Шаг 5. После согласованного выпуска — первая реальная проверка.** Войди на главной Academy → открой `https://golovalisaia-hub.github.io/-/ai.html?lesson=5&subject=qa` → выбери «Дай задание» → напиши «Дай одно упражнение по шагам воспроизведения ошибки» → нажми «Отправить» только один раз. Ожидается предметное задание, а не сообщение о ключе. Затем отправь собственный ответ на разбор. Только после получения ответа говорим, что интеграция действительно работает. Сравни изменение счётчика расходов в OpenAI с числом запросов, не публикуя содержимое ключа.

### Что делать при ошибках

| Сообщение или ситуация | Что проверить |
| --- | --- |
| «Войди в Academy» | Войди на главной тем же владельческим аккаунтом. Обычному пользователю функция закрыта. |
| «Ключ ещё не обнаружен» | Верный Supabase-проект; точное имя `ACADEMY_OPENAI_API_KEY`; нажата кнопка Save. |
| «Ключ обнаружен», но вопрос не отвечает | Это не подтверждение работоспособности: смотри точное текстовое сообщение после отправки. |
| «OpenAI отклонил ключ или доступ» | Используй ключ OpenAI, а не Supabase/BasisWeb; проверь активность ключа и право Write для Responses API. |
| «Лимит или нехватка средств» | Проверь API Billing, доступные кредиты и лимиты проекта; после пополнения баланс может обновиться не сразу. |
| «Запрос или модель отклонены» | Проверь доступ `gpt-5.6-terra` в проекте. Дополнительный секрет `ACADEMY_OPENAI_MODEL` необязателен: функция допускает `gpt-5.6-luna`, `gpt-5.6-terra`, `gpt-5.6-sol`; по умолчанию Terra. |
| «Лимит: 5 / 30» | Подожди до сброса квоты. Даже неуспешный вызов поставщика может занять слот квоты. Не повторяй запрос много раз подряд. |

Для диагностики передавай **только текст ошибки**, без ключа, заголовка `Authorization`, содержимого ответа с личными данными или скриншотов с секретами.

## Педагогическая приёмка после выпуска

- QA, урок 6: в отчёте только заголовок «не работает», нет среды, шагов и наблюдения. Наставник должен назвать недостающие поля и не объявлять дефект найденным.
- Английский, урок 3: `You am ready.` → предложение исправить `You are ready.` и задать короткий вопрос; не обещать проверку произношения.
- Python, упражнение 1: код печатает очищенную строку, но не возвращает её → пояснить различие `print` и `return`, не заявляя о выполнении программы.
- «Подсказка» → нет полного решения. При смене предмета диалог начинается отдельно; при сетевом сбое текст не теряется.

CI выполняет тесты с заглушками OpenAI и авторизации, не списывая деньги и не проверяя реальный ключ. Реальный ответ и ощущения от Safari проверяются отдельно.

Официальная документация: https://platform.openai.com/docs/quickstart/make-your-first-api-request ; https://supabase.com/docs/guides/functions/secrets ; https://help.openai.com/en/articles/9186755 .
