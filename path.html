    После сохранения обеих практик календарная задача SEVER закрывается автоматически. Python пока не требуется.

    Как работает прогресс, календарь и дополнительные материалы?

    Для каждого из первых 14 уроков есть отдельная задача Academy в SEVER. Она закрывается только после сохранения практик QA и английского одного урока. При снятии отметки задача снова открывается. Архивные задания с обязательным Python не являются частью текущего маршрута.

    Напоминания зависят от настроек SEVER и разрешений устройства. Уже отправленные уведомления нельзя отменить задним числом.

    Для тренировки произношения можно дополнить занятия упражнениями уровня A1 ↗.
