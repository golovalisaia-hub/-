# Academy — отдельная учебная платформа

Это самостоятельный статический проект. **Код приложения SEVER не изменяется.** Главный адрес Academy перенаправляет в `studio.html`: один путь обучения вместо двух конкурирующих способов ставить галочку.

## Что уже реализовано

- 84 оригинальных учебных задания по QA, Python и английскому (первый 12-недельный этап). У каждого урока три блока, вопросы, теория и практическая работа.
- Кнопка «Продолжить с непройденного» и переход к следующему уроку сразу после завершения предыдущего. В один календарный день разрешено завершить несколько последовательных уроков; даты их первоначального расписания остаются прежними.
- Отдельная адаптивная страница `studio.html` для телефона и компьютера.
- Python-консоль в `python-worker.mjs` на Pyodide 314.0.7. Код исполняется в отдельном Web Worker, без передачи туда сессии и ключей. Есть поле для тестовых строк `input()`; после первого запуска библиотеке требуется загрузиться с CDN, и в этой версии после загрузки нужно нажать «Запустить код» повторно. Долгий бесконечный цикл прерывается завершением воркера примерно через 9 секунд после старта исполнения. Запуск без исключения не доказывает, что код корректен по заданию.
- Практические QA-вопросы и словарная проверка английского. Это самостоятельный тренажёр, **не чат с живой моделью ИИ и не автоматическое экспертное оценивание**.
- Отдельные таблицы `public.academy_blocks` и `public.academy_sessions` в существующем облаке Supabase: черновики и завершённые блоки синхронизируются с аккаунтом владельца; учебный таймер сохраняет фактическую длительность завершённой сессии.
- Только если сервер подтвердил все три блока, Academy перечитывает конкретную задачу `IT · День NN/84:` и отмечает её выполненной, обновляя метаданные `sync_versions.fields.completion`. Другие задачи, заметки и привычки не изменяются.
- Ошибка синхронизации выводится явно с кнопкой повторения; фальшивого подтверждения успеха нет.
- GitHub Actions выполняет `node --check` и проверяет структуру 84 уроков и элементы учебного интерфейса.

## Статус шестимесячной программы

Подробный план на 26 недель находится в [ROADMAP-6-MONTHS.md](ROADMAP-6-MONTHS.md). **Полностью прописаны только первые 84 урока.** Недели 13–26 — план проектов, автотестов, портфолио и подготовки к собеседованиям; ежедневные задания второй части ещё не реализованы и не внесены в календарь. Не путайте дорожную карту с готовой шестимесячной LMS и не обещайте работу к фиксированной дате.

## Как открыть

После публикации GitHub Pages основной адрес `https://golovalisaia-hub.github.io/-/` переходит на `https://golovalisaia-hub.github.io/-/studio.html`. Репозиторий проекта: `golovalisaia-hub/-`. Публикация и доступность для реального браузера проверяются отдельно от существования исходников.

Войдите в Academy **тем же аккаунтом**, который используется в календаре. Сессия на этом домене своя, повторный вход может потребоваться. На сайте сохраняется только публичный publishable key; `service_role` и ключи LLM не используются в браузере. Доступ к строкам Academy ограничен RLS по `auth.uid()` и роли `owner` в `profiles`, клиентам `anon` не выданы разрешения на таблицы Academy. В таблице `tasks` остаются существующие политики владельца.

Черновики дополнительно сохраняются локально, если сеть пропала, но для перемещения между устройствами необходимо дождаться облачного сохранения. Если сессия таймера не записалась, оставьте вкладку открытой и повторите сохранение. Учебное время является показанием запущенного вручную таймера, не независимой проверкой учёбы.

## Что пока не готово / что нужно проверить

- Реальный авторизованный E2E в браузере: вход → три блока → запись задачи в SEVER → обновление SEVER на втором устройстве. CI проверяет синтаксис и связи в коде, а не этот сценарий.
- AI-наставник с настоящими ответами и проверкой решений: нужен отдельный серверный endpoint и безопасные настройки расходов. Пока встроены фиксированные вопросы, подсказки по темам и работающая Python-консоль.
- Вторая половина шестимесячной программы: ежедневные уроки ещё надо написать, валидировать и связать с календарём. Сейчас Academy не создаёт задачи за пределами имеющихся 84 дней.
- Тексты ранее упомянутых учебников не найдены среди доступных файлов. Задания оригинальные, полные тексты книг и объёмные цитаты не публикуются; точное соответствие конкретному изданию не заявляется.
- Приватность: репозиторий и статические материалы пока публичны. Для ограничения доступа ко всему сайту потребуется отдельно настроенный хостинг с серверной проверкой посетителя. Делать репозиторий приватным в одиночку недостаточно, чтобы обеспечить доступ только владельцу.

## Структура

`index.html` — переход в учебную среду; `studio.html`, `studio.css`, `studio.js` — интерфейс; `python-worker.mjs` — выполнение Python; `curriculum.js` — первый этап; `ROADMAP-6-MONTHS.md` — план развития; `tests/smoke.cjs` и `.github/workflows/academy-checks.yml` — автоматические проверки. Старые `app.js` и `styles.css` не загружаются главным адресом и оставлены только для истории исходников.
