# Academy — обучение по этапам

Основной сайт: https://golovalisaia-hub.github.io/-/ — автоматически открывает **новый маршрут QA + English** (`path.html`). Начинай с ручного тестирования с абсолютного нуля и параллельно изучай английский. Python — **позже**, после самостоятельной контрольной по QA; следующие языки — по необходимости. Это не 3 обязательных предмета каждый день.

## Что сделано для нового маршрута

- `path.html`, `path.css`, `path.js`, `path-lessons.js` — отдельный учебный кабинет в фирменной тёмно-синей и лаймовой палитре, адаптивный для ПК и телефона.
- 14 вводных тем QA + 14 английских занятий с собственными объяснениями, разборами, упражнениями и двумя вопросами с обратной связью на каждый блок. Английские фразы можно озвучить средствами браузера при наличии поддержки. Это **вводный модуль, а не завершённый курс тестировщика или полноценный A1**.
- Самостоятельная письменная работа, критерии самопроверки, отдельная отметка практики для каждого предмета. Только две отметки QA и English образуют пройденный урок; можно проходить несколько уроков в один день. Правильность свободного текста автоматически не оценивается. «Практика пройдена» не означает «профессия освоена».
- После входа под личным аккаунтом владельца черновики и результаты сохраняются в `public.academy_path_progress` с отдельной RLS-защитой. Если облако не подтвердило запись, приложение показывает ошибку и сохраняет резервный локальный черновик. Пользователь без входа может просматривать материалы, но не менять прогресс. Авторизованное сохранение в настоящем аккаунте на двух устройствах **ещё требует ручной проверки**.
- Новая таблица не использует галочки SEVER как доказательство освоения. Новый маршрут **не закрывает старые задачи календаря**: они исторически требуют QA+Python+English, и закрытие их за два предмета исказило бы данные. Перед автоматической синхронизацией нужно согласовать и создать новую схему календарных задач. Код приложения SEVER не изменялся.

## Старые материалы, которые сохранены

`studio.html` — прежние 84 комбинированных занятия QA/Python/English, Python-консоль Pyodide через браузерный Worker, подсказки, учебные сессии и прежняя интеграция с задачами SEVER. Этот раздел **архивный по учебной логике**: он не является стартовым путём для новичка. Его можно открыть для справки, но при завершении он работает по прежнему правилу трёх обязательных блоков.

`library.html` — личный книжный дневник с конспектами, их редактированием и удалением. Его дополнительные Python-поля не обязательны для обучения QA. Книги не загружены целиком и главы конкретных изданий не сверены.

[ROADMAP-6-MONTHS.md](ROADMAP-6-MONTHS.md) — план на шесть месяцев: основы QA → инструменты, API и SQL → самостоятельный QA-проект и проверка → Python с нуля → автоматизация и другие языки по цели. Это **дорожная карта**, а не обещание освоить профессию или свободный английский за шесть месяцев. Полные новые QA-first уроки после вводного модуля ещё нужно написать.

## Проверки

`Academy checks` проверяет JavaScript, структуру вводных уроков, старые материалы и отсутствие записи нового маршрута в `tasks`. `Academy browser E2E` запускает Chromium на экранах 1440/390/320, проверяет отдельные QA/English ответы, сохранение и восстановление черновика с изолированной имитацией облака, блокировки незавершённой практики, старую Python-консоль и библиотеку. `Academy iPhone WebKit smoke` проверяет опубликованный сайт на мобильных профилях. `Academy public site health` проверяет HTTP 200 и наличие файлов на GitHub Pages.

**Ограничения:** эти проверки не подтверждают наличие навыков у ученика, доступность на конкретном iPhone, корректность произношения, работу авторизации в реальной личной учётной записи на двух устройствах или полный цикл синхронизации новой программы с календарём. ИИ-наставник с семантической проверкой пока не подключён. Репозиторий и GitHub Pages публичны; приватность планируется на заключительном этапе.

## Технические файлы

`index.html` — переход к `path.html`; `path-lessons.js` — новый авторский вводный курс; `path.js` — независимый прогресс; `vendor/supabase.js` — локальная копия клиента Supabase. `studio.html`, `studio.js`, `curriculum.js`, `lesson-guide.js`, `foundation.js`, `learning-checks.js`, `academy-quality.js`, `python-worker.mjs` — прежний тренажёр. `library.html`, `library.js` — дневник. `tests/` и `.github/workflows/` — проверки.
