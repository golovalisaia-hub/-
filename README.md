# Academy — отдельная платформа для занятий

Academy — самостоятельный сайт в репозитории `golovalisaia-hub/-`. Репозиторий и код планера `golovalisaia-hub/sever-planner` не изменяются. Основной адрес Academy ведёт на учебную среду `studio.html`; материалы публикуются на GitHub Pages.

## Реализовано

- **84 тематических урока** (12 недель, первый этап программы). В каждом — QA, Python, English, оригинальные объяснения, вопрос и самостоятельная практика.
- Кнопка **«Продолжить с непройденного»**. После одного урока можно немедленно открыть следующий; несколько уроков за день допустимы, при этом первоначальные даты календаря не переписываются.
- **Python-консоль** с редактором кода, тестовыми строками `input()` и настоящим исполнением через Pyodide `v314.0.7` в отдельном Web Worker. В библиотеку Python требуется загрузка из CDN и повторное нажатие «Запустить» после сообщения о готовности. Воркер прерывается по таймауту. Запуск без исключения не означает правильное решение задачи.
- **Проверка QA-ответа** по структуре: длина, шаги и ожидаемый результат. В Python нужно запустить код и своими словами объяснить его результат. Это эвристики самопроверки, не экспертная оценка корректности.
- **Английский**: слово дня, простое грамматическое правило, пять словарных карточек и четыре вопроса на повторение перед завершением блока.
- **Учебный помощник с подготовленными подсказками**: объяснение текущей темы, начало решения, разбор структуры ответа. Это не подключённая языковая модель и не живой чат с ИИ.
- **Сохранение прогресса**: таблицы `academy_blocks` и `academy_sessions` в пользовательском Supabase с ограничениями RLS по владельцу. Ответы сохраняются как черновики и завершённые блоки, ручной таймер фиксирует завершённые учебные сессии. Локальная копия черновика служит запасным вариантом при потере сети.
- **Автоматическая галочка в календаре**: после подтверждения всех трёх блоков сервером Academy перечитывает строго одну соответствующую учебную задачу `IT · День NN/84:` владельца и записывает завершение с синхронизационными метаданными. Другие задачи и пользователи не изменяются. Ошибки отображаются явно, есть повторная синхронизация.
- **Отдельная книжная библиотека** (`library.html`): личный дневник чтения с названием книги, темой главы, собственным конспектом, QA-заданием и Python-экспериментом; создание, редактирование и подтверждённое удаление. Таблица `academy_reading` приватна через RLS. Тексты книг не копируются и сторонним читателям личные записи не раскрываются.
- **Адаптивный интерфейс** для ноутбука и мобильных устройств; в CI проверяется ширина экрана 1440, 390 и 320 px. На узком экране блок прогресса свёрнут, чтобы урок начинался на первом экране: кнопка «Продолжить», выбор урока и навигация «Уроки · Книги · Календарь» остаются на виду. От 1400 px код и вывод Python-консоли стоят рядом.
- **Запасная копия модуля входа**: `@supabase/supabase-js` грузится с CDN, а если CDN недоступен, страница подхватывает локальную копию `vendor/supabase.js` (та же версия 2.57.4 из npm-пакета; при обновлении её нужно обновлять вручную). Pyodide остаётся только на CDN: без сети Python-консоль не запустится.

## Автоматические тесты

- `Academy checks` проверяет синтаксис и структуру исходных 84 уроков, валидирует подсказки, тесты структуры ответов и 336 вариантов повторения английского.
- `Academy browser E2E` запускает реальный Chromium и Pyodide (`print(1 + 2) → 3`), проверяет навигацию и отсутствие горизонтальной прокрутки на трёх размерах экрана, отсутствие доступа у гостя к книжному дневнику.
- Отдельный **изолированный тест**, используя поддельную учётную запись, имитирует завершение QA, Python, английского и подтверждает изменение ровно одной задачи своего пользователя, а затем сохранение, редактирование и удаление записи в книжном дневнике. Никакие настоящие учебные задачи в ходе теста не закрываются.

## Шестимесячный маршрут и ограничения

План на 26 недель находится в [ROADMAP-6-MONTHS.md](ROADMAP-6-MONTHS.md). **Готовы 84 ежедневных урока первого этапа.** Недели 13–26 в виде дорожной карты: проекты, автотесты, портфолио и собеседования. Дневные задания этих недель пока не написаны и не внесены в календарь. Academy не гарантирует трудоустройство за фиксированный срок.

**Не реализовано:** настоящий AI-наставник с серверным ключом и проверкой решений; отдельный backend и согласованная модель затрат ещё требуются. Точные главы учебника Эрика Матеса не привязаны к изданию без проверки файла книги. Публичный GitHub Pages-сайт пока не закрыт по доступу (приватность договорились настраивать при финальном запуске).

**Ограничения тестирования:** Chromium-проверки проходят с гостевым доступом и изолированной имитацией авторизации; реальный авторизованный сценарий «Academy → Supabase → SEVER на другом устройстве» и iPhone Safari **ещё не проверены**. Отсутствие ошибок CI не доказывает отсутствие всех ошибок на пользовательском устройстве.

## Вход и безопасность

Открыть уроки: https://golovalisaia-hub.github.io/-/studio.html

Книги: https://golovalisaia-hub.github.io/-/library.html

Войди в Academy тем же аккаунтом, что используешь в SEVER. Браузерная сессия отдельная. В коде сайта используется только публичный publishable key, но не секретный service-role. Новые таблицы с персональными данными имеют RLS: чтение для `anon` отключено, пользователь ограничен собственными записями и ролью `owner`. Выполнение учебных заданий не затрагивает исходники SEVER.

## Структура проекта

`index.html` — переход на курс; `studio.html`, `studio.css`, `studio.js`, `studio-extras.js` — занятия; `learning-checks.js`, `academy-quality.js/.css`, `lesson-guide.js` — оригинальные подсказки и самопроверка; `python-worker.mjs` — Python; `vendor/supabase.js` — запасная локальная копия клиента Supabase; `library.html/.css/.js` — книжный дневник; `curriculum.js` — 84 урока; `ROADMAP-6-MONTHS.md` — проект продолжения. `tests/*.cjs`, `.github/workflows/*` — проверки. Старые `app.js` и `styles.css` оставлены в истории, основной сайт их не загружает.
