# SEVER Academy — отдельная учебная платформа

Отдельный статический сайт, **не часть репозитория SEVER**. В `golovalisaia-hub/sever-planner` ничего менять не требуется. Этот репозиторий ранее был пустым; его имя `-` осталось прежним.

## Возможности

- 84 учебных дня с 20 сентября по 12 декабря 2026 года: QA, Python, English.
- Каждый день три блока: теория, пример, конкретная практика и поле для собственного ответа.
- Программа по 12 неделям, даты и статусы занятий из собственного календаря SEVER после входа.
- Вход через **ту же учётную запись Supabase Auth**. У сайта отдельная браузерная сессия: войти необходимо ещё раз. Он работает только с `profiles.role = owner`.
- Ответы и промежуточные отметки блоков сохраняются **только в локальном хранилище текущего браузера**, в пространстве имён пользователя. Не удаляйте данные браузера до завершения дня, если хотите сохранить черновики. Не используйте общие компьютеры для личных ответов.
- После самостоятельного завершения QA, Python и English сайт перечитывает строго одну собственную задачу `IT · День NN/84:` и меняет только `completed`, `completed_at`, `updated_at`, `sync_versions.fields.completion`. Права и ограничения Supabase RLS остаются такими же, как у SEVER. Другие задачи, заметки и привычки не изменяются.
- Если сервер не подтвердил запись — показывается ошибка и кнопка повторной синхронизации. Успех не имитируется.

## Публикация на GitHub Pages

В репозитории `golovalisaia-hub/-` откройте **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**. После публикации проект будет доступен по адресу `https://golovalisaia-hub.github.io/-/` (проверяйте статус публикации в настройках; наличие файлов в GitHub не означает, что Pages уже включён).

Исходники: `index.html`, `styles.css`, `curriculum.js`, `app.js`, `icon.svg`. Сборка не нужна. Для CDN используется фиксированная версия Supabase JS 2.57.4. При блокировке CDN вход не работает, но программа остаётся доступной для чтения.

## Что нужно знать

- Это учебный MVP, а не AI-репетитор: Python не запускается и не оценивается автоматически. Пользователь сам выполняет упражнение в VS Code и отмечает блок после ответа.
- Сайт использует только открытый **publishable key**. Секретного `service_role` в коде нет; изменение задачи проверяется RLS и уточняющими фильтрами `user_id`, `id` и названием.
- Вход с другой учётной записью, отсутствие нужной задачи, проблемы с соединением или изменение протокола синхронизации блокируют автоматическую галочку.
- Английская привычка и настройки уведомлений в SEVER не изменяются.
- Перед первым реальным завершением учебного дня откройте обе вкладки, войдите в Академию и проверьте в SEVER, что одна нужная задача переключилась в выполненные. В этом сеансе полноценная проверка авторизованного браузера не выполнялась.

## Техническая заметка

Публичный статический код курса виден всем, но личные задачи доступны только пользователю, авторизованному в Supabase с действующей RLS-политикой. Незавершённые блоки остаются локальными; финальное состояние хранится в задачах SEVER. Автоматическое завершение использует версионирование поля `completion`, чтобы не подавлять более новые изменения иных полей при синхронизации.
