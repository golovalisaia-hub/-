# Python Academy Full

Полный интерактивный ридер для репозитория:
https://github.com/justxor/pythonroamap2026

## Что делает эта версия

- при первом запуске автоматически получает рекурсивное дерево репозитория GitHub;
- загружает все 121 файла текущего репозитория (все файлы в нём текстовые): `course/`, `course/prompts/`, `templates/` и корень;
- сохраняет их в IndexedDB браузера;
- строит полное содержание и навигацию;
- отображает Markdown как учебник;
- поддерживает внутренние ссылки между главами;
- строит оглавление главы по H2/H3;
- ведёт прогресс по реальным разделам;
- сохраняет заметки и закладки;
- делает полнотекстовый поиск по локальной копии;
- показывает код starter-проектов;
- позволяет обновить локальную копию с GitHub.

## Важно

При первом открытии нужен интернет, чтобы синхронизировать исходный репозиторий.
После успешной синхронизации материалы хранятся локально в браузере и могут читаться из кэша.

Откройте `Python-Academy-Full.html` двойным кликом. Если конкретный браузер запрещает сетевые запросы из `file://`,
запустите папку через простой локальный сервер:

```bash
python -m http.server 8000
```

и откройте http://localhost:8000/Python-Academy-Full.html

## Источник и атрибуция

Учебный контент синхронизируется из `justxor/pythonroamap2026`.
Сайт является отдельным интерфейсом для чтения, прогресса, поиска и заметок.


## Проверка

Версия проверена на синтаксис JavaScript и на сценарии: первая синхронизация, переходы между разделами, Markdown, просмотр Python/YAML/TOML как кода, поиск, прогресс, заметки, закладки и мобильное меню. Обновление кэша сделано безопасным: старая локальная копия не очищается до успешной загрузки новой.
