# Python Academy Full

Полный интерактивный ридер для репозитория:
https://github.com/justxor/pythonroamap2026

## Что делает эта версия

- при первом запуске автоматически получает рекурсивное дерево репозитория GitHub;
- загружает все 121 файла текущего репозитория (все файлы в нём текстовые): `course/`, `course/prompts/`, `templates/` и корень;
- сохраняет их в IndexedDB браузера;
- строит полное содержание и навигацию;
- отображает Markdown как учебник;
- поддерживает внутренние ссылки между главами;
- строит оглавление главы по H2/H3;
- ведёт прогресс по реальным разделам;
- сохраняет заметки и закладки;
- делает полнотекстовый поиск по локальной копии;
- показывает код starter-проектов;
- позволяет обновить локальную копию с GitHub.

## Важно

При первом открытии нужен интернет, чтобы синхронизировать исходный репозиторий.
После успешной синхронизации материалы хранятся локально в браузере и могут читаться из кэша.

Откройте `index.html` двойным кликом (или через GitHub Pages: `/-/python-full/`). Если конкретный браузер запрещает сетевые запросы из `file://`,
запустите папку через простой локальный сервер:

```bash
python -m http.server 8000
```

и откройте http://localhost:8000/

## Источник и атрибуция

Учебный контент синхронизируется из `justxor/pythonroamap2026`.
Сайт является отдельным интерфейсом для чтения, прогресса, поиска и заметок.


## Что исправлено и добавлено

- Отметка раздела, закладка и «вся глава пройдена» больше не перерисовывают статью и не кидают в начало страницы.
- `__init__`, `**kwargs` и прочее внутри `кода` больше не превращаются в жирный текст.
- Прогресс и оглавление больше не съезжают, если в блоках кода есть строки `## …`; старые отметки сохраняются.
- Якоря как на GitHub: ссылки `[раздел](#раздел)` и `file.md#раздел` работают; ссылки на папки открывают её `README.md`.
- Адрес страницы отражает главу (`#/course/stage-01-basics.md#раздел`): обновление страницы и кнопка «Назад» работают.
- «Далее», «Назад» и «Продолжить обучение» идут в порядке этапов (раньше — по алфавиту); «Продолжить» помнит последнюю главу.
- Обновление с GitHub скачивает только изменённые файлы (по sha), понятная ошибка при лимите GitHub API, кнопка «Повторить».
- Поиск: подсветка совпадений, фрагмент действительно содержит найденное слово, клик открывает нужный раздел.
- Вложенные списки, отмеченные чекбоксы `[x]`, таблицы с пустыми ячейками, относительные картинки.
- HTML из Markdown очищается до вставки в страницу (в инертном `<template>`).
- На телефоне и планшете доступны оглавление, заметки и закладки (под статьёй); меню закрывается после выбора главы.
- Кнопки «Предыдущая / Следующая» внизу главы; клавиша `/` — поиск, `Esc` — закрыть меню.
- Тема по умолчанию берётся из настроек системы; повреждённый localStorage не ломает запуск.

## Проверка

Версия проверена на синтаксис JavaScript и на сценарии: первая синхронизация, переходы между разделами, Markdown, просмотр Python/YAML/TOML как кода, поиск, прогресс, заметки, закладки и мобильное меню. Обновление кэша сделано безопасным: старая локальная копия не очищается до успешной загрузки новой.
