# Python Academy Full

Полный интерактивный ридер для репозитория:
https://github.com/justxor/pythonroamap2026

## Что делает эта версия

- при первом запуске автоматически получает рекурсивное дерево репозитория GitHub;
- загружает все 121 файла текущего репозитория (все файлы в нём текстовые): `course/`, `course/prompts/`, `templates/` и корень;
- сохраняет их в IndexedDB браузера;
- строит полное содержание и навигацию;
- отображает Markdown как учебник;
- поддерживает внутренние ссылки между главами;
- строит оглавление главы по H2/H3;
- ведёт прогресс по реальным разделам;
- сохраняет заметки и закладки;
- делает полнотекстовый поиск по локальной копии;
- показывает код starter-проектов;
- позволяет обновить локальную копию с GitHub.

## Важно

При первом открытии нужен интернет, чтобы синхронизировать исходный репозиторий.
После успешной синхронизации материалы хранятся локально в браузере и могут читаться из кэша.

Откройте `index.html` двойным кликом (или через GitHub Pages: `/-/python-full/`). Если конкретный браузер запрещает сетевые запросы из `file://`,
запустите папку через простой локальный сервер:

```bash
python -m http.server 8000
```

и откройте http://localhost:8000/

## Источник и атрибуция

Учебный контент синхронизируется из `justxor/pythonroamap2026`.
Сайт является отдельным интерфейсом для чтения, прогресса, поиска и заметок.


## Что исправлено и добавлено

**Чтение**
- Markdown разбирается как на GitHub: вложенные блоки кода и списки внутри пунктов (нумерация не сбрасывается после кода), `\`` и `\*`, `_курсив_`, `<https://…>`, `&amp;`, строчный HTML (`<kbd>`, `<b><code>`), переносы строк, выравнивание в таблицах.
- `__init__`, `**kwargs` внутри кода не превращаются в жирный текст.
- Подсветка синтаксиса Python, YAML/TOML/Dockerfile/bash, JSON и SQL без внешних библиотек (работает офлайн).
- Якоря совпадают с GitHub: ссылки `[раздел](#раздел)`, `file.md#раздел`, ссылки на папки; Ctrl/⌘+клик открывает ссылку в новой вкладке.
- Оглавление подсвечивает текущий раздел; «Продолжить» возвращает туда, где остановился.
- Кнопка «✓ Отметить главу и перейти дальше» внизу главы; снятие отметки со всей главы спрашивает подтверждение.
- Отметка раздела и закладка не перерисовывают статью и не сбивают прокрутку.
- Адрес страницы отражает главу и раздел: обновление страницы работает, «Назад» возвращает на прежнее место.

**Прогресс**
- Ключ раздела теперь — его якорь, а не порядковый номер: если автор курса добавит раздел выше, отметки не съедут. Старые отметки переносятся один раз автоматически (и из старых файлов экспорта).
- У файлов с кодом больше нет «разделов» из `# комментариев`, которые нельзя было отметить.
- Изменения из другой открытой вкладки подхватываются, а не затираются.
- На странице прогресса — список заметок.

**Синхронизация**
- Файлы скачиваются по конкретному коммиту: кэш CDN не подсунет старый текст под новым sha.
- Скачиваются только изменённые файлы; если изменений нет — один лёгкий запрос к API.
- Раз в 6 часов тихо проверяется, не обновился ли курс («Есть обновление» на кнопке).
- Понятная ошибка при лимите GitHub API (со временем сброса), кнопка «Повторить» при первом запуске без сети.
- Повторное нажатие во время синхронизации не запускает вторую.
- Без IndexedDB (приватный режим) учебник работает из памяти и честно предупреждает об этом.

**Интерфейс**
- На телефоне в меню есть все разделы (Поиск, Прогресс и т.д. раньше были недоступны), меню закрывается касанием снаружи.
- Нет горизонтальной прокрутки на телефоне ни в одной главе курса (длинные заголовки, код, таблицы, окно синхронизации).
- Starter-проекты сгруппированы по проектам, файлы подписаны путём (`src/app/main.py`, а не десять «Main»); группы сворачиваются.
- Правая панель не занимает место вне режима чтения; поиск показывает количество, Enter открывает первый результат.
- HTML из Markdown очищается до вставки в страницу; id из текста (например, заголовок «Toc») не ломает интерфейс.

## Автотест

`tests/python-full-reader.cjs` — 33 проверки в Chromium против поддельного GitHub из `tests/fixtures/python-full`
(сеть не нужна). Запускается в CI (`.github/workflows/python-full.yml`) при изменении ридера:

```bash
npm install --no-save playwright && npx playwright install chromium
node tests/python-full-reader.cjs
```

## Проверка на реальном курсе

На полной копии `justxor/pythonroamap2026` (121 файл, 56 Markdown-глав): все разделы и якоря оглавления совпадают
с отрисованной страницей, 922 из 934 возможных старых ключей прогресса переносятся (12 оставшихся относились к
«разделам» внутри блоков кода, которых на странице никогда не было), ни в одной главе нет горизонтальной прокрутки
на ширине 390 px, ошибок JavaScript нет. Две ссылки в самом курсе ведут на несуществующие заголовки
(`stage-00-environment.md#бесплатные-ресурсы`, `stage-17-llm-apps.md#урок-12-eval-guardrails`) — это ошибки исходника.
